# Bao-cao-thuc-tap-BA
Tài liệu và cập nhật báo cáo thực tập Business Analyst – hệ thống CV Marketplace (Light Human).

## Demo web (`demo/`)
- `index.html` – trang sử dụng: Khách hàng, HR, CTV, Người giới thiệu
- `admin.html` – trang quản trị: Admin
- `u.html` – trang link cá nhân của Ứng viên
- Dữ liệu mẫu lưu trên trình duyệt (localStorage), hai trang dùng chung dữ liệu. Nút "Khôi phục dữ liệu mẫu" đưa về trạng thái ban đầu.
